## 🚀 How to Host on Netlify (1-Click Drag & Drop)

### Option 1: Drag & Drop (Zero Setup, 10 Seconds)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Sign in or create a free Netlify account.
3. Drag and drop this entire `website/` folder right onto the Netlify drop zone.
4. Your site will be instantly live with a free SSL `https://[your-site-name].netlify.app` URL!

### Option 2: Connect via GitHub
1. In Netlify Dashboard, click **Add new site** > **Import an existing project**.
2. Select your GitHub repository: `AmanYadav9516/AAYA-AI-Assistant`.
3. Set **Base directory** to `website`.
4. Leave Build command empty.
5. Set **Publish directory** to `website` (or `.`).
6. Click **Deploy AAYA**! Any future git pushes will automatically update your landing page.

## ⚡ How to Host on Vercel (1-Click)

1. Go to [Vercel](https://vercel.com) and log in with GitHub.
2. Click **Add New...** > **Project**.
3. Import your `AmanYadav9516/AAYA-AI-Assistant` repository.
4. In the Project Configuration:
   - Click **Edit** next to **Root Directory**.
   - Select the `website` folder.
5. Click **Deploy**!
6. Your site is live with a free high-speed CDN and custom domain options.
